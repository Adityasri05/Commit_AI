## 1. Introduction to Artificial Intelligence

Artificial Intelligence (AI) is the field of computer science focused on building systems that perform tasks commonly associated with human intelligence, such as reasoning, perception, language understanding, planning, and decision-making.

### Common categories
- **Narrow AI:** Designed for a specific task, such as spam filtering or image recognition.
- **General AI:** A hypothetical system with broad, human-like ability across many intellectual tasks.
- **Generative AI:** Models that create new content, including text, images, audio, and code.

### Core building blocks
1. Data provides examples or context.
2. Algorithms define how a system learns or reasons.
3. Models encode patterns or learned behavior.
4. Evaluation measures how well the system performs on relevant tasks.

### AI workflow
Problem definition → Data collection → Preparation → Model or system development → Evaluation → Deployment → Monitoring.

### Key takeaway
AI is not a single algorithm. It is a broad discipline that combines data, algorithms, computing, and domain knowledge to solve problems.
